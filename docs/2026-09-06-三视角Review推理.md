# 三视角 Review 推理：赛制 × 榜单案例 × IT 架构（2026-09-06）

## 视角一 · 赛制：规则把差异空间逼到哪几个变量

规则事实(已核)：Add/Search 两操作；Answer/Judge 固定(判词含 typo 容忍、prefer most recent、列表全项且 no-extras、时间粒度严格)；top_k=100；七维+细项；学术榜须绑 commit/代码、可复现审查；禁跨样本共享状态/禁硬编码公开题；第二期为滚动窗口(9/20-10/31、11 月中旬出分)，每轮提交后可看私有回执。

推得四个'规则级'结论：
1. **Search 输出的两个自由度 = 返回什么 + 什么顺序**。检索器可任意内部加工，只要预算允许——顺序自由度被我们低估：top1 是唯一直接决定 Hit@1 的面，而判官'取最新支持记忆'意味着**时间顺序本身就是答案结构**（读时仲裁是顺规则而为，不是额外功能）。
2. **内部延迟档是自选变量**：官方按 Slow/Medium/Fast 标注但 Accuracy 榜独立；若第二期评分不惩罚慢档，Axis III 的受控深检索是合法预算支出(ReFind 已用此策略并获 #2)——我们卡 200ms 红线是**自我设限**，应改为'按需分级预算'(默认快、标记题深)。
3. **滚动窗口 = 带真实奖励的闭环**：每轮提交有私有回执 → 我们把'单变量假设→回执→失败桶归因'做成显式流程(现 A2 分桶+gate 只是离线侧，缺'私有回执接入'环)，这是**开发循环的架构**，和运行时代码同等重要；首轮目标是'拿基线+校准尺子'而非冲分。
4. **合规是硬约束而非加分**：隔离/脱敏/TTL/禁跨样本状态；'会话内学习'(Axis I 访问层)恰好在禁区内侧——合法差异空间里唯一的时间维度学习通道。

## 视角二 · 榜单案例：形态推断『哪两维值得打』

案例事实：前三差 0.22、前 8 差 1.1(需无系统性短板)；冠军碎片化(7 维冠军在 4 系统)；前三无单项冠军；AMI 零治理拿 D 第一；ReFind agentic 慢拿 B/A 高；官方极简基线拿 H 第一；C 轴开源天花板 24.6(MemMachine 37.9) vs 工业 56-60。

推断：
- **进前 8 = 无短板 + 2-3 个近冠维度**；我们 A/D/G/H 有底但 A 拥挤(需稠密门控)、E 无语义难追——**把筹码压在开放榜最弱的 C 与规则执行 G、加保底 H 安全**：C 全场 18-24.6 且工业 56-60 证明'同一判官下时序可被系统做到'——开放榜没人做对时间建模，这是**结构性机会窗**(检索派都不建时间态)；G 我们已有 RULE Wing，差邻接完整性(判答后)。
- AMI '无治理 D 第一' + 判官 'prefer most recent' 共同指向：**治理维的赢法是读时时间序，不是写入期删除**——支持 Axis II 作为 D+C 双吃的架构件。
- ReFind #2 用慢档换准确 → 混合档(快默认+标记深)可能同时吃准确与'不慢档'口碑。

## 视角三 · IT 架构：以架构原则重审我们的形态与三轴

原则视角审视：
- **关注点分离**：内容层(不可变、唯一事实源)与访问/仲裁层分离 = Axis I/II 符合；现状单表混 mem_type/links 已近可拆——建议把'排序特征'与'内容'在接口上分离(SearchResult 已只回 content，内部可另带仲裁元数据)。
- **不可变性与可复现**：FSRS touch 使 Search 有状态=复现性负债(滚动多轮私有回执对比会被状态污染)——参赛档建议关闭 touch(或按 scope 快照隔离)；R1/R4 时间件是纯函数无状态，安全。
- **单一写者与 WAL**：OK；官方 150M 字符量级需先压测写入吞吐与 FTS 规模(stress 300chunk 已验基线，再扩 10× 看 P95 拐点)。
- **复杂度税**：现默认关旋钮 10+ 个，维护面大——参赛版应'默认档冻结为发布面'(v 标签化 config)，旋钮只在研究档。
- **可观测/审计**：我们领先；补'私有回执接入'台账后闭环完整。
- **三轴架构风险**：Axis I 需内容/访问双写一致性(事务内)、随 TTL/删除级联；Axis II 聚簇键(主体×属性)的启发式精度决定仲裁质量——可复用治理 v2 的 slot 键；Axis III 门控阈值需成对标定且默认关，防引入不确定性。

## 综合推理：固定件下的顶层形态
1. 运行面：『内容层原文不可变 + 读时 recency 仲裁(Axis II，D/C 双吃) + 相对时间写时锚定(F2/R1 时间件) + 条件深度第二遍(Axis III，默认快档、标记题深档) + 缺席/安全(H 保底)』——把'时间即答案结构'变成排序性质，是检索派里没人做的一层；
2. 学习面：滚动窗口=真实 reward 闭环——每轮提交接私有回执→按七维失败桶归因→单变量改动→重交；提交版冻结默认档(旋钮发布面 v 标签化)；
3. 面选择：无系统性短板(A/D/G/H 覆盖、C 保底不拖后腿) + C/G 近冠押注 + H 免费分；
4. 不做：不与固定稠密赛 A 顶分(留 R7 门控方案待数据)、不上图/门控交换/集合重排(负结果)、不把仿真叙事写入分口径。
