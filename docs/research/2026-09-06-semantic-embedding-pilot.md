## 三、解释与处置

1. 跨词汇（住在哪→甲字十二号）确实是语义嵌入的用武之地——机器首次在该题命中；
2. 但朴素『语义重排取代哈希』会伤另一类查询（主线/意图宽泛题）：余弦把『总结性』记忆当不相似；
3. 候选池太小（top30）且章节记忆长文本混排，语义对长记忆区分弱；
4. **推荐集成形态（不翻转默认）**：hybrid RRF——FTS/hash 精确通道保持强信号（章节 boost、RULE、编号），
   语义只作为**软加权补充通道**（openai provider + 向量列 dim 兼容/分 provider 库），且需在完整 11 题+真实
   写前 recall 集上做 A/B（含时延与成本：~0.6s/embed、2620 条全量重建 ≈ 27 分钟/次）；
5. 与 NER 的关系：实体标签质量（D2：噪音 53%、覆盖低）制约『实体+语义』协同；语义试点不等 NER。
