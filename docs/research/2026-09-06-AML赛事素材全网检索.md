- 赛事：**Agent Memory Challenge 2026**（AML 首期公开评测），组织方 AML（牛津/南洋理工/清华/东南等 20+ 高校机构）。

## 5. 结论与落地建议

1. **「上届考核内容」的真相**：官方不出题集；一手素材 = 契约仓库（已有镜像）+ Smoke 公开子集（申请制）+ 公榜。**要官方口径，必须先走 evaluation 申请拿 AML Key**——这是 9/20 前唯一该排的队。
2. **本地回放近似**（不混入官方成绩、按「本地代理结果」标注）：LoCoMo + LongMemEval-S + PersonaMem-v2 三个可得的上游集 × 官方 pipeline answer 模板 + gpt-4o-mini 顶替 judge（DEV 作者同法，明示为内部估计）——这正是 audit_2026-09-06 报告 L1 缺口的补法。
3. **能力维度字母表以官方 docs/api-guide 为准**：官网能力页字母为 A-E,G,H（规则=G、认识论=H），与本项目内部 维度F=规则/维度G=认识论 的字母编号可能不一致——报名文档前按官方口径重对齐一次（避免自造维度名）。
4. **警示素材**：DEV「grounding header +12 分但主动不提交」案例 = 本项目 Search 只回原文、不 coach 判官的设计是对的；可作为边界自觉写进方案（不是承诺，是诚实）。
