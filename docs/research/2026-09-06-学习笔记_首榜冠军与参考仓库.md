# 学习笔记：AML 首榜冠军与参考仓库（2026-09-06）

> 依据：浏览器/搜索直读官方仓库、赛事官网、MemoraX 通稿/访谈、DEV 自跑文、InfiniteMemOs/brainctl/agentmemory 仓库、Mem0 综述。
> **证据分级**：L1=官方口径/仓库直读｜L2=第三方自有实测、可复算｜L3=自报、需独立复算。分级贯穿全文——任何数字先看分级再看大小。

## 1. 首榜画像（我们参加的『上届』）

- 工业榜：**MemoraX 58.02 分第一，七科全一**；MemOS 第二；TencentDB Memory / Mem0 / Supermemory 等上榜（L1，官网公榜+joto 报道）。
- MemoraX 公开面（L3/部分 L1）：天大郝建业团队创业；对外叙事=『可学习记忆/内源记忆』（区别于外挂 RAG）；产品面=给 Codex/Claude Code/DeepSeek Harness 等做共享记忆层（memorax-code，npm），组织还维护 ScriptMem 基准与 dsh-patchouli 插件；**内部机制未公开=黑盒**。
- **三个认知校准（比任何数字都重要）**：
  1. 冠军 58.02 分 vs Mem0/Letta 等在公开 LoCoMo 自报 90%+（L3）——**AML 官方套件远严于公开上游自评**（私有划分 + typo/no-extras/时间粒度判官）。本地自测数字与官方榜没有换算关系，只有『同一官方契约回执』才可比。
  2. 冠军是『七科全一』——**均衡覆盖赢，不是单点最强**。Cortexa 全维度自测矩阵方向正确，报名材料应讲『无短板』而非只讲某一亮点。
  3. 对手全是『分层检索+更新治理』的商业记忆产品——赛道上没有单 FTS/单向量裸方案；Cortexa 的 RRF 双路+治理链处在合理光谱内，缺的是官方规模的测量（与 L1 结论一致）。

## 2. 参考仓库学习卡（逐仓：设计 → 证据 → 可借鉴 → 避坑）

### 2.1 agentmemory（rohitg00）——『低成本双路已够用』的活证据
- 设计：BM25+Vector（all-MiniLM-L6-v2，**无 API key**）+ 图 BFS；bench:longmemeval 全流程可复跑；逐条标『自有实测 vs 厂商自报』。
- 证据（L2）：LongMemEval-S 检索准确率 **95.2%**（BM25+Vector）；**BM25-only 86.2%**。厂商自报列（MemPalace ~96.6、oracle ~94.4）明确标注未独立复现。
- 借鉴：①轻量词法+轻量嵌入即可在 LME-S 到 95%——我们 hash 通道≈BM25 级，缺的只是同口径对照实验；②『数字分级标注』的表格纪律直接可抄。
- 避坑：别拿他们表里的自报列当基准。

### 2.2 brainctl（TSchonleber）——SQLite 同架构 + 检索回归门
- 设计：单 SQLite；检索=FTS5(stem)→sqlite-vec(Ollama)→**RRF hybrid**；检索后按 recency/salience/Q-value/Bayesian 置信重排；benchmark 预设备展平 recency/salience；**CI 回归门：P@1/P@5/MRR/nDCG@5 掉 >2% 即构建失败**；LongMemEval 锁快照基线（n=289）。
- 借鉴（高价值）：**检索质量回归门**——Cortexa 的 check.py 只有正确性（259 passed），没有『检索分不得回退』的门；加『11 题（后续官方集）hit@1/MRR 回归阈值』是低成本高杠杆内部资产。RRF 混合路线与我们一致=互相印证。
- 避坑：ARAS/REM/connectome/代币市场等叙事层严重过载——营销叙事稀释可信度；Cortexa 机制表『名实对齐』路线是对的，别学这种包装。

### 2.3 InfiniteMemOs（marcot3ssar1）——确定性 episodic + 复现胶水
- 设计：确定性自托管 episodic（K3 引擎），NVIDIA embed（llama-nemotron 768D）+ numpy 检索复核，QA/judge 固定 gpt-4o-mini temp0 且 verbatim 上游提示词；rerank 负结果报告公开；『Black-box engine, brute top-10, dedup off, no rerank, 1 run』等行级配置写死。
- 证据：LoCoMo QA **70.49%（L3 自报）**；top-50 行 75.90。数值需复算，但**评测纪律本身可学**。
- 借鉴：①固定 reader/judge + verbatim 提示词 + 行级配置写死 = 我们回放器该有的复现形态；②负结果报告入仓 = 与我们『负结果留档』文化同源。
- 避坑：NVIDIA API/OpenRouter 依赖说明其分数非全离线——我们 hash 离线路线仍是差异化点。

### 2.4 Mem0 综述（mem0.ai，厂商立场）——校准与自报通胀标本
- 数字：Mem0 自报 LoCoMo 92.5% / LongMemEval 94.4% / BEAM-1M 64.1%（L3）；agentmemory 表另列 Letta(LoCoMo 83.2)、Mem0(68.5，旧)等；Zep 自报 96.1/94.7 但第三方测其 75.1（L3 对 L2 冲突）——**同一基准，自报分差 20+ 分**。
- 借鉴：评测必须统一口径的活教材（AML 的存在理由）；公开集分数只能做方法排序，不能做任何质量宣称。我们所有本地数字一律标『本地代理结果』。
- 避坑：与任何厂商数字比大小都无意义；只与自己的成对实验比。

### 2.5 DEV Muninn 自跑复盘（已读，复习要点）
- 设计：keyword+semantic+query-expansion 融合；supersede 覆盖旧陈述；LoCoMo 自跑 ≈66%（full）/~72.9%（best，gpt-4o-mini 顶替 judge=内部估计）；『grounding header』+12 分主动不提交。
- 借鉴：query-expansion 是有实证的增益手段（L2 内部估计），Cortexa 可做**零 LLM 的词法扩展版**（同义词/去停用词扩充进 FTS，受约束、默认关）作候选实验；supersede 方向与我们一致。
- 避坑：grounding/coach 判官类提示词 = 边界问题；我们 Search 只回证据，不碰。

## 4. 一句话
