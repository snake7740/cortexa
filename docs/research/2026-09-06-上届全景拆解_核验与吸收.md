## 2. 结构性认知（对 Cortexa 路线的影响）

### 2.1 『写时少加工 + 查询强检索』是开源榜前排共识，我们路线同向
- InvMem(不预总结/历史即事实源)、ReFind(零预构建)、AMI(双写但 raw 优先)全部拒绝写入期用 LLM 重写记忆为不可逆结构——与 Cortexa『原文即存储单元、无模型抽取层』一致。
- 开源榜前二都没有写入期 LLM 预构建；差异全在查询侧（分块细度/加权融合/邻接扩写/agent 多轮/语域改写）。我们缺的也正是查询侧（A 系列 L1/L4 结论不变，再获一票）。

### 2.2 冠军是学习派（MemoraX 58.02），但不在我们可比面内
- AMI 论文指出：AML 契约(gpt-4o-mini 仅限 Add/Search 期间)把『模型即存储』整类架构排除——学术方法榜的参赛面=外部索引族。
- 结构性含义：在学术榜内追赶目标应是 InvMem/ReFind/AMI 这一族（45±0.2 紧咬），MemoraX 的数字是另一赛道的参照系，不直接当追赶目标。

### 2.3 分维度差距表给了我们『补短板优先级』的官方口径
- 开源榜首维度：A 事实召回 56.8–57.8 / B 多跳 ~45 / C 时序 ~18–22 / D 治理 32.6–38 / E 个性化 52.8–54.6 / G 规则执行 28.3–30.8 / H 安全 ~30–33。
- 与我们 21 题本地样本的失败结构对照：channel-miss 集中在数量/亲属/跨表述(A 面弱于 57)与相对时间(C 最低分档 18-22 我们同样差)一致；D 治理维度我们 v2 修复后接近开源榜首(AMI 37.95, 靠保真而非治理；我们=治理 v2+原始保留混合)。
